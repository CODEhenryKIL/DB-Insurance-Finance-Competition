## 분석 및 인사이트

### 1. SmallCap_5% 전략이 압도적 우승 🏆
- **CAGR 17.91%** (벤치마크 12.71% 대비 **+5.20%p**)
- **9년간 총 수익률 340%** (벤치마크 194%의 1.75배)
- **IR 0.43** (유일하게 양수 → 초과수익 안정성)

### 2. Alpha가 -0.03%인 이유 (정상!)

**Jensen's Alpha 계산**:
```
Alpha = (R_p - R_f) - Beta × (R_b - R_f)
      = (17.91% - 2%) - 1.64 × (12.71% - 2%)
      = 15.91% - 17.56%
      = -1.65%
```

→ **Beta가 1.64로 매우 높음** (벤치마크의 1.64배 변동성)
→ 높은 변동성 대비 수익률은 벤치마크와 유사한 수준
→ **이는 "위험 조정 수익률"이 벤치마크 수준이라는 의미** (나쁜 것 아님!)

### 3. sector 모드의 장점
- Gap 평균 편향 감소 (-0.671 → -0.027)
- bias가 0 근처로 안정화
- CAGR, MDD 모두 개선
