## 1️⃣ 피처 정의 (M1, M2, M3)

### 회계 재작성 (Restatement) 공식

```
I (투자)      = R&D + (SG&A × 0.3)           ← SG&A의 30%를 무형자산 투자로 간주
A (상각)      = (I_{t-1} + I_{t-2} + I_{t-3}) / 3   ← 3년 정액 상각
AdjOI (조정OI) = OI + I - A                  ← 투자 효과 반영한 영업이익
```

### 피처 계산식

| 피처 | 공식 | 의미 | 클리핑 범위 |
|------|------|------|-------------|
| **m1** | `AdjOI / max(\|OI\|, ε)` | 이익 복원력 | [-5, +5] |
| **m2** | `I_t / Avg(I_{t-1}, I_{t-2})` | 투자 가속도 | [0, 10] |
| **m3** | `AdjOI / Equity` | 본업 기초체력 (ROE 유사) | [-5, +5] |

### 타겟 변수 (y)

```
y = ln(PBR) = ln(MarketCap / Equity)

※ 섹터 상대 변환: y_relative = y - Universe_Median(y) by Year
※ PBR 범위 클리핑: [0.01, 100]
```
