## 변경 사항

### 1. Y 타겟 정의 변경

| 항목 | exp_003 (기존) | exp_004 (변경) |
|------|----------------|----------------|
| **Y 정의** | ln(PBR) - 전체 평균 | ln(PBR) - **섹터 중앙값** |
| **의미** | 절대적 저평가 학습 | **섹터 내 상대적 저평가** 학습 |

### 2. 핵심 개선 사항

**기존 문제점**:
- 섹터간 PBR 수준 차이가 큼 (Tech ≫ Utilities)
- 전체 평균 기준 시 고PBR 섹터 과대평가 가능

**변경 (섹터 상대)**:
```
Y = ln(PBR_i) - Median(ln(PBR)_sector)

예시:
- Tech 기업 A: ln(5.0) - ln(4.0) = +0.22 (섹터 내 고평가)
- Tech 기업 B: ln(3.0) - ln(4.0) = -0.29 (섹터 내 저평가) ← 선택!
- Utilities 기업 C: ln(1.2) - ln(1.3) = -0.08 (섹터 내 저평가)
```

### 3. 코드 변경

**`config/constants.py`**:
```python
Y_TARGET_MODE = 'sector'  # 섹터 상대 PBR
```

**`modeling/step4_train_predict.py`** (Y 전처리):
```python
# 섹터별 중앙값 계산
sector_medians = df.groupby(['FiscalYear', 'Sector'])['y'].transform('median')
df['y'] = df['y'] - sector_medians  # 섹터 상대 ln(PBR)
```
