### 2. Train/Val Split 개선: 섹터별 층화 추출

**기존 (exp_002) 문제점**:
- 기업별 랜덤 분리 시 특정 섹터가 Val에 몰릴 수 있음
- 예: Tech 기업이 Val의 80%를 차지하면 편향 발생

**변경 (exp_003)**:
```
각 섹터에서 동일 비율(20%)로 Val 기업 선정

┌─────────────────────────────────────────────────────────────┐
│  Tech: 100개 기업 → Train 80개 / Val 20개 (20%)             │
│  Healthcare: 80개 기업 → Train 64개 / Val 16개 (20%)         │
│  Industrials: 60개 기업 → Train 48개 / Val 12개 (20%)        │
│  ... (모든 섹터 동일 비율)                                    │
└─────────────────────────────────────────────────────────────┘
```

### 3. 핵심 개선 사항

| 항목 | 설명 |
|------|------|
| **섹터 균형** | 모든 섹터에서 동일 비율로 Val 추출 → 특정 섹터 편향 방지 |
| **기업 일관성** | 동일 기업은 모든 연도에서 같은 그룹 (Train or Val) |
| **3년 전체 학습** | 금융시장 스타일 변화를 놓치지 않음 |
| **강한 규제** | weight_decay=1e-2로 과적합 방지 강화 |
