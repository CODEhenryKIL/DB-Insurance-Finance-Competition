## 변경 사항

### 1. Y 타겟 정의 변경

| 항목 | exp_003 (기존) | exp_005 (변경) |
|------|----------------|----------------|
| **Y 정의** | ln(PBR) - 전체 평균 | **ln(PBR) 그대로** |
| **의미** | 상대적 저평가 학습 | **절대적 저평가** 학습 |

### 2. 핵심 개선 사항

**변경 (절대 PBR)**:
```
Y = ln(PBR_i)  # 전처리 없음

예시:
- Tech 기업: ln(5.0) = 1.61 (고평가)
- Value 기업: ln(0.8) = -0.22 (저평가) ← 선택!
```

**특징**:
- 섹터 무관하게 절대적으로 낮은 PBR 기업 선호
- Value 투자 관점에서 직관적
- 섹터 편향 발생 가능 (저PBR 섹터 과대표집)
