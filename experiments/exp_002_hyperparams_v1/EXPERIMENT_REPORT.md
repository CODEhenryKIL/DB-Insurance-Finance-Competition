### 2. Train/Validation/Test Split 개선

**기존 (exp_001)**:
```
Train: [t-3, t-2, t-1] → Test: [t]
(Validation 없음, 3년 전체 데이터로 500 epochs 강제 학습)
```

**변경 (exp_002) - Cross-sectional Split**:
```
3년 전체 사용 + 기업별로 Train(80%)/Val(20%) 분리
→ 3년간의 금융시장 스타일 변화를 모두 학습!
```

### ⚠️ Cross-sectional 데이터의 올바른 Train/Val 분리

| 항목 | 설명 |
|------|------|
| **목적** | 최근 3년간의 금융시장 **스타일 변화**를 학습 |
| **문제** | 연도순 split(2년 Train/1년 Val) 시 → 실질적으로 **2년만 학습** |
| **해결** | **기업별 Cross-sectional Split** - 3년 전체 학습 가능 |

```
올바른 방식 (Cross-sectional Split):
┌───────────────────────────────────────────────────────────────┐
│       2017         │       2018         │       2019          │
│   기업 A,B,C (T)   │   기업 A,B,C (T)   │   기업 A,B,C (T)    │  → Train 80%
│   기업 D,E (V)     │   기업 D,E (V)     │   기업 D,E (V)      │  → Val 20%
└───────────────────────────────────────────────────────────────┘
                    3년 전체의 스타일 변화 학습!

※ 같은 기업은 항상 같은 그룹 (Train or Val)
※ 시간 순서 문제 없음 - 같은 시점의 다른 기업 데이터로 검증
```

**핵심 원칙**:
1. **3년 전체 학습**: 금융시장 스타일 변화를 놓치지 않음
2. **기업별 분리**: 동일 기업은 Train 또는 Val 중 하나에만 존재
3. **Data Leakage 방지**: Val 기업의 과거 데이터가 Train에 포함되지 않음

## 분석 및 인사이트

### 1. 성과 하락 원인

| 요인 | 설명 |
|------|------|
| **LR 상향 (10배)** | 학습률 0.01은 단순 선형 모델에 과도할 수 있음 → 최적점 overshoot |
| **Early Stopping** | Validation Loss 기준 조기 종료 → 학습 부족 가능성 |
| **L2 규제** | weight_decay=1e-4가 가중치를 과도하게 축소했을 가능성 |
| **Train/Val Split** | 학습 데이터 감소 (3년 → 2년) |

### 2. 긍정적 측면

- **과적합 방지**: Early stopping으로 불필요한 반복 제거
- **일반화 검증**: Validation set 도입으로 모델 일반화 능력 검증 가능
- **재현성 향상**: 명확한 Train/Val/Test 분리로 실험 재현성 확보

### 3. 개선 방향 (다음 실험)

1. **LR 조정**: 0.01 → 0.005 또는 0.003으로 하향 검토
2. **Patience 조정**: 10 → 20으로 증가 (충분한 학습 보장)
3. **weight_decay 조정**: 1e-4 → 1e-5로 하향 검토
4. **K-Fold Cross Validation**: 연도별 CV로 더 robust한 검증
